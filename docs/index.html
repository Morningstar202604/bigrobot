An AI workspace for the chat account you already own.

把你已有的聊天账号，变成自己的 AI 工作台。

BigRobot takes over an existing account and shows what is really there: groups, members, files and history. An agent sits on top, with tool calling, retrieval, permissions and an audit trail.

BigRobot 接管一个现成账号，把真实的群、成员、文件和历史摊开；上面放一个 Agent，带工具调用、检索、权限和审计。

What it does

能做什么

The account stays the centre; the agent works inside the boundaries you set.

账号是中心，Agent 只在你设定的边界里行动。

Take over the account

接管账号

Start the protocol, scan a QR code, keep it alive with a watchdog and restart backoff.

启动协议端、扫码登录，看门狗与退避重启维持在线。

See what is there

看得见

Group and direct history, member lists with roles, group files, notices and friends.

群聊与私聊历史、成员整表含角色、群文件、群公告、好友。

Act with proof

操作有据

Send, recall, mute, kick, edit a card, publish a notice. Risk tiers, approvals and a hash-chained audit.

发送、撤回、禁言、踢人、改名片、发公告；风险分级、审批和哈希链审计。

Agent, not autocomplete

Agent，不是自动补全

Function calling with fallback, multi-step runs, knowledge collections, reminders and future tasks.

function calling 与降级、多步执行、知识库集合、提醒与未来任务。

Add capability without forking

加能力，不改核心

Declarative HTTP packs and MCP servers join the same tool registry; channels are capability declarations.

声明式 HTTP 扩展与 MCP 进入同一套工具注册表；渠道按能力声明接入。

Local models, no cloud

本地模型，不出本机

Download a sub-2B GGUF model, run it with llama.cpp and switch in one click. The console tightens prompts for small models automatically.

下载 2B 以下 GGUF，llama.cpp 本机运行，一键切换；控制台会自动收紧小模型的提示词。

Works without a model key

没 Key 也能跑

Rules and retrieval keep the group alive instead of failing closed.

规则 + 检索继续运行，不会因为没配模型就静默。

Principles

原则

Account first

账号优先

A chat account is not a message endpoint. Its groups, members and files are the product surface.

聊天账号不是消息接口；群、成员和文件才是产品表面。

Capabilities, not platform names

按能力声明

The console renders from declarations. A new platform is a declaration, not a UI rewrite.

界面按声明渲染；接新平台是加声明，不是重写界面。

Nothing pretends to work

不假装成功

Missing protocol, transcription or audio support returns a real error, never a plausible fake.

缺协议、转写或音频支持时如实报错，不给一个看起来合理的假结果。

Start

快速开始

One process serves the console and the API. QQ needs a local NapCat instance.

一个进程同时提供控制台和 API；QQ 需要本地 NapCat。

git clone https://gitcode.com/badhope/bigrobot && cd bigrobot
python -m venv .venv
.venv/bin/pip install -r requirements.txt
ADMIN_TOKEN=change-me .venv/bin/python -m uvicorn core.main:app --port 8010
# open http://127.0.0.1:8010
